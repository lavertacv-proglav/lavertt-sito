# Sito LAVERTT (lavertt.com)

Sito statico generato dalle pagine del canvas "LAVERTT sito".

- `src/pages/` — una pagina per file (Home = `Main.html`)
- `src/partials/` — header, footer, stile e script condivisi
- `public/` — file copiati così come sono (favicon, robots.txt; mettere qui `logo.png` per usare il logo vero)
- `build.js` — genera il sito in `dist/`. In cima al file: numero WhatsApp e link del questionario.

Ogni modifica pubblicata su `main` viene messa online in automatico da Vercel.
